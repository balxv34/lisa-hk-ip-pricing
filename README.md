## 香港家宽IP和机房IP到底差在哪

差在IP段的注册属性上。普通VPS的IP从机房批发段里分配，whois和ASN查出来是数据中心；家宽IP从外网看是本地宽带运营商的住宅段，风控系统判定的是一个真实存在的香港家庭宽带。平台限制的正是这个属性，所以同样的注册、养号、观看行为，机房IP容易被限功能甚至清零，家宽IP的通过率高得多。
